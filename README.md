# NetFaultLab

> Deterministic network-fault injection for integration tests. Point it at a service, declare the failure you want — connection drop, added latency, packet loss, slow start — and it reproduces that exact condition on every run instead of the ad-hoc tc/iptables scripts teams paste between projects.
